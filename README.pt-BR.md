# color-contrast-core

Luminância relativa e razão de contraste WCAG 2.x para cores hex sRGB.
Zero dependências, Node >= 22.

Parte do laboratório open source da LOFRANO TECNOLOGIA. MIT.

```sh
npm test          # 6 testes, node:test, sem dependências
npm run demo
```

Somente hex; limiares 4.5/7 (normal) e 3/4.5 (grande). MIT — veja `LICENSE`.
